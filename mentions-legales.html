Lorsque vous réservez en ligne (ou que le salon enregistre votre rendez-vous) :

  • prénom et nom ;
  • adresse email ;

Allergies et informations de santé : si vous nous signalez une allergie dans la demande particulière, vous acceptez qu’elle soit utilisée uniquement pour la sécurité de votre soin. Uniquement le salon, via un espace administrateur protégé par mot de passe. Vos données ne sont pas visibles par les autres visiteurs du site. Nous faisons appel à des prestataires techniques, qui agissent pour notre compte :

Si vous estimez que vos droits ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL : www.cnil.fr.

Les réservations sont stockées dans une base de données protégée : seul le compte administrateur du salon peut les lire. Les données sont transmises de façon chiffrée (HTTPS).
